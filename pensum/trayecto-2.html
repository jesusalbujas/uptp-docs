Trayecto II - Técnico Superior Universitario en Informática

El Trayecto II profundiza en el desarrollo de software, administración de redes y bases de datos, formando Técnicos Superiores Universitarios capaces de diseñar, implementar y mantener sistemas informáticos.

🎯 Perfil Profesional

Al finalizar este trayecto, el estudiante obtiene el Título de Técnico Superior Universitario en Informática (TSU), que lo capacita para:

  • Desarrollar aplicaciones de software
  • Administrar redes de computadoras
  • Diseñar y gestionar bases de datos
  • Aplicar metodologías de ingeniería de software
  • Liderar proyectos informáticos de mediana complejidad

⏱️ Duración

Duración Estimada

3 Trimestres (aproximadamente 36-42 semanas)

📚 Unidades Curriculares

📐 Matemática II (3 UC)

Descripción: Matemáticas avanzadas aplicadas a la informática, incluyendo estadística, métodos numéricos y análisis de algoritmos.

Contenidos principales:

  • Estadística descriptiva e inferencial
  • Probabilidad aplicada
  • Métodos numéricos
  • Análisis de complejidad algorítmica
  • Matemática para bases de datos (álgebra relacional)

🌐 Redes de Computadora (3 UC)

Descripción: Fundamentos de redes de computadoras, protocolos de comunicación, configuración y administración de redes locales.

Contenidos principales:

  • Modelo OSI y TCP/IP
  • Topologías de red
  • Direccionamiento IP (IPv4, IPv6)
  • Protocolos de red (HTTP, FTP, DNS, DHCP)
  • Configuración de switches y routers
  • Cableado estructurado
  • Seguridad básica en redes

Competencias:

  • ✓ Diseñar topologías de red
  • ✓ Configurar dispositivos de red
  • ✓ Diagnosticar problemas de conectividad
  • ✓ Implementar seguridad básica de redes

🧠 Formación Crítica II (3 UC)

Descripción: Continuación del análisis crítico de la realidad, profundizando en la ética profesional y el impacto social de las tecnologías de información.

Contenidos principales:

  • Ética en el desarrollo de software
  • Privacidad y protección de datos
  • Software libre vs. software propietario
  • Impacto social de las TI
  • Derechos digitales

💻 Programación II (4 UC)

Descripción: Programación orientada a objetos, estructuras de datos avanzadas y desarrollo de aplicaciones de mayor complejidad.

Contenidos principales:

  • Programación Orientada a Objetos (POO)
  • Clases, objetos, herencia, polimorfismo
  • Estructuras de datos (listas, pilas, colas, árboles)
  • Algoritmos de ordenamiento y búsqueda
  • Recursividad
  • Manejo de excepciones
  • Programación en Java, C++, Python u otros lenguajes POO

Competencias:

  • ✓ Diseñar sistemas usando POO
  • ✓ Implementar estructuras de datos complejas
  • ✓ Optimizar algoritmos
  • ✓ Desarrollar aplicaciones modulares y reutilizables

🌍 Proyecto Sociotecnológico II (3 UC)

Descripción: Desarrollo de un sistema de software que atienda necesidades comunitarias, aplicando metodologías de ingeniería de software.

Contenidos principales:

  • Levantamiento de requerimientos
  • Análisis de sistemas
  • Diseño de software
  • Implementación de soluciones
  • Pruebas de software
  • Documentación técnica y de usuario

Productos esperados:

  • 📋 Documento de requerimientos
  • 🎨 Diseño del sistema
  • 💻 Aplicación funcional
  • 📚 Manual técnico y de usuario
  • 📊 Presentación de resultados

🛠️ Ingeniería del Software I (3 UC)

Descripción: Metodologías, técnicas y herramientas para el desarrollo sistemático de software de calidad.

Contenidos principales:

  • Ciclo de vida del software
  • Metodologías ágiles (Scrum, XP)
  • Análisis y diseño de sistemas
  • UML (diagramas de casos de uso, clases, secuencia)
  • Gestión de requerimientos
  • Control de versiones (Git)
  • Pruebas de software

Competencias:

  • ✓ Aplicar metodologías de desarrollo
  • ✓ Modelar sistemas con UML
  • ✓ Gestionar proyectos de software
  • ✓ Utilizar herramientas de control de versiones

🎨 Electiva (3 UC)

Descripción: Materia de especialización según intereses del estudiante.

Opciones comunes:

  • Desarrollo web (HTML, CSS, JavaScript)
  • Programación móvil (Android, iOS)
  • Inteligencia artificial básica
  • Ciberseguridad
  • Cloud Computing
  • DevOps básico

🗄️ Base de Datos (3 UC)

Descripción: Fundamentos de bases de datos relacionales, lenguaje SQL y diseño de esquemas de datos.

Contenidos principales:

  • Conceptos de bases de datos
  • Modelo relacional
  • SQL (DDL, DML, DCL)
  • Consultas básicas y avanzadas
  • Diseño de bases de datos
  • Normalización (1NF, 2NF, 3NF)
  • Integridad referencial
  • Gestores de bases de datos (MySQL, PostgreSQL)

Competencias:

  • ✓ Diseñar bases de datos relacionales
  • ✓ Escribir consultas SQL eficientes
  • ✓ Normalizar esquemas de datos
  • ✓ Administrar bases de datos básicas

🏆 Actividades Acreditables (3 UC)

Descripción: Participación en actividades que complementan la formación técnica y profesional.

Actividades válidas:

  • Certificaciones técnicas (Oracle, Microsoft, AWS)
  • Participación en hackathons
  • Contribuciones a proyectos de software libre
  • Cursos de actualización tecnológica
  • Asistencia a congresos y seminarios

🎓 Certificación Obtenida

Título TSU

Técnico Superior Universitario en Informática

Este título universitario de pregrado acredita al profesional para:

  • Desarrollar sistemas de software completos
  • Administrar infraestructura de redes
  • Diseñar y gestionar bases de datos
  • Aplicar metodologías de ingeniería de software
  • Liderar equipos de desarrollo

💼 Campo Laboral

Con el título de TSU, el egresado puede desempeñarse como:

  • 💻 Desarrollador de Software
  • 🌐 Administrador de Redes
  • 🗄️ Administrador de Bases de Datos Jr.
  • 🛠️ Analista Programador
  • 📊 Coordinador de Proyectos de TI
  • 🔧 Ingeniero de Soporte Técnico
  • 🌍 Desarrollador Web

✅ Competencias Desarrolladas

Al finalizar el Trayecto II, el estudiante será capaz de:

Competencias Técnicas

✅ Desarrollar aplicaciones usando programación orientada a objetos

✅ Diseñar, implementar y administrar redes de computadoras

✅ Crear y gestionar bases de datos relacionales

✅ Aplicar metodologías de ingeniería de software

✅ Realizar análisis de sistemas y levantamiento de requerimientos

✅ Trabajar en proyectos de desarrollo de software en equipo

✅ Utilizar herramientas de control de versiones y colaboración

🚀 Siguiente Paso

Continuación del Programa

Tras obtener el título de TSU, el estudiante puede avanzar al Trayecto III - Desarrollador de Aplicaciones, especializándose en desarrollo avanzado de software, sistemas operativos y modelado de datos.
